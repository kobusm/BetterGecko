# Icon artwork

`noto-gecko-3d.png` is the 🦎 (U+1F98E) image from Google's
[Noto Emoji](https://github.com/googlefonts/noto-emoji) project (`3D/png/512/emoji_u1f98e.png`),
licensed under the [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0).
Copyright 2013 Google LLC.

`scripts/make_icons.py` composites it onto the green background to produce every app icon
(iOS, Android launcher, Play Store, support site). Run it from the repo root after changing the artwork.
